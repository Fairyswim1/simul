제20회 모의고사 1번 문제 시뮬레이션

슬라이더를 움직여 각도(θ)에 따른 점 P, Q의 움직임과 넓이 변화를 관찰하세요.

컨트롤러

0° 30° (π/6) 45° (π/4)

실시간 데이터 분석

선분 길이:
  • |BP| (tan θ) = 0
  • |CQ| = 0
(1)번 조건 확인:
  • |BP| × |CQ| = 0
  • 목표값 1/9 = 0.1111...
(2)번 넓이 비 확인:
  • 직각삼각형 S₁ (APQ) = 0
  • 직각삼각형 S₂ (PCQ) = 0
  • 넓이 비율 (S₂ / S₁) = 0
  • 이론상 최댓값 (√2-1)/2 ≈ 0.2071

극한값

범례

왼쪽 포물선 y=kx²
오른쪽 포물선 y=k(x−k)²
원래 포물선 y=x² (참고)
점 P (t, t²)
점 Q (s, 0)
점 R (t/k+ks, t²/k)
색칠 영역 S(k)
① 핵심 변환: R의 좌표
  • 1P = (t, t²), t∈[−1,1] / Q = (s, 0), s∈[0,1]
  • 2OR = (1/k)OP + k·OQ 대입
  • 3R = (t/k + ks, t²/k)
  • 4u = t/k, v = ks 로 치환하면
    R = (u+v, ku²)
② 경계 포물선 유도
u ∈ [−1/k, 1/k], v ∈ [0, k]

고정 y에서 u = ±√(y/k)
x 범위: [u, u+k]

왼쪽 경계: x = −√(y/k)
→ y = kx² (x ≤ 0 쪽)

오른쪽 경계: x = k+√(y/k)
→ y = k(x−k)² (x ≥ k 쪽)
③ 케이스 분기 조건
두 구간 [−√(y/k), k−√(y/k)]
과 [√(y/k), k+√(y/k)] 의 겹침 여부:

겹침 조건: y ≤ k³/4
최대 y값: y_max = 1/k

k³/4 ≤ 1/k
↔ k⁴ ≤ 4 ↔ k ≤ √2
④ Case i (k ≤ √2): 넓이 계산
아래 (y∈[0, k³/4]): 연속 구간
위 (y∈[k³/4, 1/k]): 좌우 두 조각
S(k) = 2·k·(1/k) − 2∫₀1/k kx² dx
= 2 − 2·(k/3)·(1/k)³
= 2 − k⁴/12
⑤ Case ii (k > √2): 넓이 계산
전 구간 y∈[0,1/k] 에서 단일 연속 구간
(중앙 구멍 없음)
S(k) = k·(1/k) + 2·(1/k)·(1/k) − 2∫₀1/k kx² dx
= 1 + 2/k² − (2/3)·k·(1/k)³
= 1 + 4/(3k²)
⑥ 극한값 & 최종 답
k→0+: Case i 식 사용
lim S(k) = 2 − 0 = 2

k→∞: Case ii 식 사용
lim S(k) = 1 + 0 = 1

2 + 1 = 3

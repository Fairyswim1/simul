📐 최종 해 영역의 수식

부등식을 x = cos(θ)로 치환하면 교집합 영역은 다음 3가지 조건으로 이루어집니다. (x ∈ [-1, 1])

  • ① 우측 하단 선분 (x = 1, θ = 0°)
    a + b < 1   =>   b < 1 - a
  • ② 우측 상단 선분 (x = -1, θ = 180°)
    a - b < 1   =>   b > a - 1
  • ③ 좌측 타원 곡선 (포락선, -1 < x < 1)
    8a² + 8a + b² < 0
    (중심이 (-0.5, 0)인 타원의 내부)

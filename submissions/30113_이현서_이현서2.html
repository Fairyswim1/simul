💡 수학적 원리 인사이트

본 문항은 변수 $k$의 변화에 따라 시스템의 행동 양식이 급격히 변하는 기하학적 임계 현상(Critical Phenomenon)을 다룹니다.

1. 스넬의 법칙과의 링크

물리학에서 빛이 서로 다른 매질을 통과할 때 최단 시간을 만족하는 경로는 스넬의 법칙($\text{Snell's Law}$)을 따릅니다. 본 문제에서 $x$축 상의 이동 비용 가중치 $k$는 일종의 상대적 굴절률 또는 매질 저항으로 볼 수 있으며, 최적 경로 조건에서 선분 $AC$가 $x$축과 이루는 사각 $\theta$와 $\cos \theta = k$라는 아름다운 평형 관계를 이룹니다.

2. 상전이(Phase Transition)와 임계값

점 $A(-10, 2)$의 기하학적 위치로 인해 선분이 누울 수 있는 최대 각도의 코사인 값은 $\frac{10}{\sqrt{10^2+2^2}} = \frac{5}{\sqrt{26}} \approx 0.9806$입니다. 이 값을 기점으로 시스템의 성격이 완전히 분리됩니다.

  • $k \ge \frac{5}{\sqrt{26}}$ 일 때: $CD$ 구간의 비용적 저항이 너무 크기 때문에 해당 구간을 $0$으로 압축하고 원점에서 두 점이 합쳐지는 것이 전체 비용을 아끼는 길입니다.
  • $k < \frac{5}{\sqrt{26}}$ 일 때: $CD$ 구간의 경제성이 확보되므로 두 점이 원점으로부터 분리되어 외곽으로 팽창하기 시작합니다.

📝 문항별 정밀 해설

[문항 1] $AC + CD + DB$가 최소가 되는 점 $C, D$의 좌표

이 문항은 가중치 $k=1$인 상황입니다. 점 $C(x_C, 0)$와 $D(x_D, 0)$에 대해 일반성을 잃지 않고 $x_C \le x_D$라 가정할 수 있습니다. 이때 비용 함수는 다음과 같습니다.

$$\text{Cost} = AC + CD + DB = \sqrt{(x_C+10)^2 + 2^2} + (x_D - x_C) + \sqrt{(10-x_D)^2 + 2^2}$$

임의의 경로에서 $x_C \le x_D$일 때, 점 $B(10, 2)$를 $x$축에 대해 대칭이동시킨 점을 $B'(10, -2)$라 하면 $DB = DB'$가 성립합니다. 따라서 전체 비용은 $AC + CD + DB'$가 됩니다. 삼각부등식에 의해 이 경로는 평면상의 두 점 $A(-10, 2)$와 $B'(10, -2)$를 잇는 직선 경로보다 언제나 크거나 같습니다.

$$AC + CD + DB' \ge AB' = \sqrt{(10 - (-10))^2 + (-2 - 2)^2} = \sqrt{400 + 16} = 4\sqrt{26}$$

등호가 성립하는 최단 경로는 직선 $AB'$가 $x$축과 만나는 교점 위에서 형성됩니다. 직선 $AB'$의 방정식은 $y = -\frac{1}{5}x$이므로 $x$축과의 교점($y=0$)은 원점 $(0,0)$입니다. 따라서 $C$와 $D$가 모두 원점에서 합쳐질 때 최소가 됩니다.

$$\therefore C(0, 0), \quad D(0, 0)$$

[문항 2] 최소 비용을 갖는 점 $C, D$가 항상 원점에 대해 대칭임 설명

비용 함수를 두 변수 $x_C, x_D$ ($x_C \le x_D$)에 대한 다변수 함수 $f(x_C, x_D)$로 정의합니다.

$$f(x_C, x_D) = \sqrt{(x_C+10)^2 + 4} + k(x_D - x_C) + \sqrt{(10-x_D)^2 + 4}$$

Case 1) $x_C < x_D$ 인 경우 (내부 극점 존재 시)
함수가 최솟값을 가지려면 각 변수에 대한 편미분 계수가 $0$이어야 하므로 다음 일계조건을 만족해야 합니다.

$$\frac{\partial f}{\partial x_C} = \frac{x_C+10}{\sqrt{(x_C+10)^2 + 4}} - k = 0 \implies \frac{x_C+10}{\sqrt{(x_C+10)^2 + 4}} = k$$ $$\frac{\partial f}{\partial x_D} = k - \frac{10-x_D}{\sqrt{(10-x_D)^2 + 4}} = 0 \implies \frac{10-x_D}{\sqrt{(10-x_D)^2 + 4}} = k$$

함수 $g(t) = \frac{t}{\sqrt{t^2+4}}$는 $t > 0$ 영역에서 도함수가 양수이므로 일대일 대응인 단조 증가 함수입니다. 따라서 두 식의 결과가 모두 $k$로 같으므로 내부 인자가 같아야 합니다.

$$x_C + 10 = 10 - x_D \implies x_C = -x_D$$

이는 두 점이 원점 $O(0,0)$에 대해 대칭 위치에 있음을 입증합니다.

Case 2) $x_C = x_D = x_0$ 인 경우 (두 점이 겹치는 경우)
$CD=0$이 되므로 비용 함수는 $2\sqrt{(x_0+10)^2 + 4} + 2\sqrt{(10-x_0)^2 + 4}$ 형태의 일변수 함수가 되며, 이는 기하학적 대칭성에 의해 오직 $x_0 = 0$ 즉, 원점 $C(0,0), D(0,0)$에서 최소화됩니다. 원점 자체는 원점 대칭 조건을 만족합니다.

따라서 모든 최소 비용 상태에서 점 $C$와 점 $D$는 항상 원점에 대하여 대칭입니다.

[문항 3] 상수 $k$를 1부터 줄여나갈 때, 점 $C, D$가 움직이기 시작하는 임계 $k$ 값

문항 2의 대칭성 결론에 따라 $D(x, 0), C(-x, 0)$ ($x \ge 0$)로 치환하면 비용 함수는 $x$에 대한 일변수 함수 $F(x)$로 단순화됩니다.

$$F(x) = 2\sqrt{(10-x)^2 + 4} + 2kx \quad (x \ge 0)$$

이 함수의 도함수를 구하면 다음과 같습니다.

$$F'(x) = 2 \cdot \frac{-(10-x)}{\sqrt{(10-x)^2 + 4}} + 2k = 2\left( k - \frac{10-x}{\sqrt{(10-x)^2 + 4}} \right)$$

함수 $h(x) = \frac{10-x}{\sqrt{(10-x)^2 + 4}}$는 $0 \le x \le 10$ 범위에서 $x$가 증가할 때 분자는 감소하고 분모는 증가하므로 전체적으로 엄격한 단조 감소 함수입니다. 즉, $-h(x)$는 단조 증가하므로 도함수 $F'(x)$는 $x$에 대해 엄격하게 증가하는 함수가 됩니다.

만약 $x=0$에서의 미분계수가 $0$ 이상($F'(0) \ge 0$)이라면, 모든 $x > 0$ 영역에서 $F'(x) > 0$이 되므로 함수 $F(x)$는 완전한 단조 증가 함수가 되어 최솟값은 경계인 $x=0$(원점 고정)에 머무르게 됩니다. 반대로 $F'(0) < 0$이 되는 순간 극소점이 $x>0$ 영역으로 밀려나며 점들이 움직이기 시작합니다. 따라서 움직임이 시작되는 임계 경계는 $F'(0) = 0$인 순간입니다.

$$F'(0) = 2\left( k - \frac{10}{\sqrt{10^2 + 4}} \right) = 2\left( k - \frac{10}{\sqrt{104}} \right) = 2\left( k - \frac{5}{\sqrt{26}} \right) = 0$$ $$\therefore k = \frac{5}{\sqrt{26}} = \frac{5\sqrt{26}}{26} \approx 0.98058$$

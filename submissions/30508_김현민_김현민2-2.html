움직이는 적분 구간 시뮬레이터

함수 f(t) 위에서 적분 구간 [x-1/2, x+1/2]이 움직일 때의 넓이 F(x)를 만들고,
아래 그래프에서 현재 F(x)의 위치와 전체 넓이를 확인합니다.
x = 0.00
함수 f(t) 현재 적분 영역 적분 구간 양끝 F(x) 그래프 F(x)와 x축 사이 영역 현재 F(x) 위치

현재 상태 및 풀이 정보

현재 x값 x = 0.00
적분 구간 [-0.50, 0.50]
현재 F(x)값 F(x) = 0.750
그래프 표시 상태 현재 F(x)만 표시 중
F(x)의 구간별 식
|x| ≤ 1/2 : F(x) = 3/4 - x²
1/2 ≤ |x| ≤ 3/2 : F(x) = 1/2(3/2 - |x|)²
|x| ≥ 3/2 : F(x) = 0
우함수 확인
위의 f(t)는 y축에 대해 대칭인 우함수입니다. 적분 구간을 x에서 -x로 바꾸면 구간이 좌우 대칭으로 이동하므로, 두 넓이는 같습니다.
따라서 F(-x)=F(x)이고, F(x)는 우함수입니다.
문제 (2) 넓이 검토
아래 그래프의 노란색 영역은 곡선 y=F(x)와 x축으로 둘러싸인 부분입니다.
전체 넓이는 1입니다.
풀이 인사이트
  • 위 그래프에서는 적분 구간이 움직이며 F(x)가 만들어지는 과정을 볼 수 있습니다.
  • 아래 그래프에서는 현재 F(x)의 위치를 먼저 확인하고, 필요할 때만 대칭 확인 버튼으로 F(-x)를 함께 볼 수 있습니다.
  • F(x)가 0이 되는 구간과 x축으로 둘러싸인 전체 넓이를 시각적으로 확인할 수 있습니다.

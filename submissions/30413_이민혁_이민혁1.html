연세대 수열 기출 시각화 시뮬레이터 (y = x²)

1. 점화식 유도 과정 (접선)

곡선 y = x² 위의 점 (xₙ, xₙ²)에서의 접선의 방정식:
y - xₙ² = 2xₙ(x - xₙ)
y = 0 대입 시 x절편 xₙ₊₁ 구하기:
-xₙ² = 2xₙ(x - xₙ)   ⇒   -xₙ/2 = x - xₙ
∴ xₙ₊₁ = xₙ / 2 (공비가 1/2인 등비수열)

2. 문제 (2)의 극한 시각화 (법선)

법선의 기울기는 -1/(2xₙ). 법선의 x절편을 bₙ이라 하면,
y - xₙ² = -1/(2xₙ)(x - xₙ) 에서 y=0일 때 bₙ = xₙ + 2xₙ³
구하고자 하는 극한의 일반항: xₙ⁴ / (bₙ - xₙ)
= xₙ⁴ / (2xₙ³) = xₙ / 2

결국 무한급수 Σ(xₙ/2) = (k/2) / (1 - 1/2) = k 가 됩니다.
